SHELTER STUDIO — редактор роликов на Python
===========================================

Внутри трейлер SHELTER, разложенный на 21 сцену. Каждую сцену можно открыть,
поменять код, слои, эффекты или тексты и сразу увидеть результат, добавить
новые сцены из библиотеки или от ИИ, собрать ролик автоматически
и выгрузить готовое видео в MP4.


ЗАПУСК
------
Нужен Python 3.10 или новее: https://www.python.org/downloads/
(в Windows при установке отметьте галочку «Add python.exe to PATH»).

  Windows:  двойной щелчок по  start_windows.bat
  Mac:      двойной щелчок по  start_mac.command
            (если macOS не даёт открыть: правый щелчок → «Открыть» → «Открыть»)
  Linux:    bash start_linux.sh

Первый запуск 1–3 минуты: программа сама ставит нужные библиотеки
(нужен интернет). Потом открывается браузер с редактором.
Окно с чёрной консолью не закрывайте — это и есть программа.
Закрыли консоль — редактор остановился (последние правки сохраняются).

Вручную, если удобнее:
  pip install -r requirements.txt
  python run.py                 (откроет последний проект)
  python run.py путь/к/папке    (откроет конкретный проект)


КНОПКИ ВВЕРХУ
-------------
  Проекты        — все ваши ролики. «Новый проект» — пустой ролик в нужном
                   формате (16:9, 9:16 для Reels/Shorts/TikTok, 1:1), «Копия
                   текущего» — другая версия ролика. «Открыть проект» — любая
                   папка проекта или zip-архив (см. ниже). Переключение — одним
                   щелчком; при запуске программы открывается последний проект.
  Автомонтаж     — собрать ролик из ваших фото и видео: выберите стиль (кино,
                   динамичный, тёплые воспоминания, нуар, кибер), заголовки
                   и подписи. Если загружена музыка — склейки встанут в такт.
                   Каждая сцена потом правится во вкладках «Слои» и «Эффекты».
  Звук           — звук ко всем сценам. «Автоматически»: удары на HITS и склейках,
                   акценты на появлении надписей, подложки и ритм по длине сцен;
                   настроение каждой сцены (эпично, трагично, напряжённо, экшен,
                   надежда, загадочно, спокойно) выбирается в списке или строкой
                   MOOD = 'tragic' в коде сцены. «Через ИИ»: задание со всем кодом
                   ролика → ответ ИИ вставляется обратно, заменяется только sound().
  Библиотека     — готовые сцены (титры, глава, цитата, отсчёт, большое число,
                   финальные титры, глитч-заставка, «фото/видео + подпись»…)
                   и ваши сохранённые. Любую можно посмотреть до добавления.
  Сцена от ИИ    — опишите сцену своими словами, программа составит точное
                   задание для ИИ (ChatGPT, Claude…): правила, справочник всех
                   команд, список ваших картинок и шрифтов. Вставьте ответ ИИ —
                   программа проверит код, покажет кадры и добавит сцену.
  Версии         — снимки всего ролика. Сохраняются сами перед экспортом,
                   автомонтажом и восстановлением; свою можно сохранить в любой
                   момент и вернуть одной кнопкой.
  Экспорт MP4    — видео 1920×1080 со звуком в папку project/exports/.


ВКЛАДКИ СПРАВА
--------------
  Код        — Python-код выбранной сцены. Превью обновляется само, пока вы
               печатаете (или по Ctrl+S). Ошибка покажется красным с номером строки.
  Слои       — видео, картинки и тексты поверх сцены без всякого кода:
               подрезка видео, скорость, звук из видео, «заполнить кадр /
               вписать / свободно», движение камеры, цвет, анимации текста.
  Эффекты    — переходы, движение камеры, цветокоррекция, глитч, VHS, свечение,
               засветки, пыль, искры, снег, дождь… с ползунками. Готовые наборы
               ставят несколько эффектов сразу, их можно раздать во все сцены.
  Тексты     — все надписи ролика. Меняются без кода.
  Медиа      — картинки, видео и музыка. «Добавить папку» (или перетащить папку)
               загрузит всё из неё в одноимённую папку; сверху — фильтр по папкам
               и типам, поиск. Щелчок по картинке/видео ставит его слоем в
               выбранную сцену, щелчок по треку — делает его музыкой ролика,
               ▶ — послушать. «Убрать белый фон» вырежет объект со светлого фона.
  Настройки  — формат кадра (16:9 / 9:16 / 1:1), шрифты по ролям (заголовки, курсив, обычный) и свои шрифты
               (.ttf/.otf), кинополосы, зерно, виньетка, звук, своя музыка.
  Справка    — все команды для сцен с примерами.


ТАЙМЛАЙН ВНИЗУ
--------------
  • каждый блок — сцена; щелчок — открыть её, двойной щелчок — перейти к ней;
  • перетащите блок, чтобы поменять порядок; тяните правый край — длина;
  • «+ Сцена» — новая сцена из шаблона, из библиотеки или от ИИ;
  • «В библиотеку» — сохранить сцену, чтобы использовать в других роликах;
  • синяя полоска сверху — какие кадры превью уже готовы;
  • цветные полоски под сценами — слои (щелчок открывает слой);
  • жёлтые метки — удары (HITS), нижняя дорожка — звук.

Превью слева
  • Пробел — play/пауза, стрелки — по кадру (Shift+стрелка — на секунду);
  • кадры рендерятся в фоне; если впереди ещё не готово, плеер подождёт.


ГДЕ ЧТО ЛЕЖИТ
-------------
  projects/               новые проекты (каждый — своя папка)
  project/project.json    порядок сцен, длины, слои, эффекты, тексты, настройки
  project/scenes/*.py     код сцен (можно править и в любом редакторе)
  project/scenes/_trash/  удалённые сцены (их можно вернуть)
  project/scenes/_history/ прошлые версии кода сцен
  project/_versions/      сохранённые версии всего ролика
  project/assets/         картинки, видео и звуки (можно по папкам)
  project/fonts/          шрифты (Oswald, Cormorant — свободная лицензия OFL)
  project/audio/          загруженная музыка
  project/exports/        готовые видео
  library/                библиотека сцен (общая для всех проектов)
  studio/                 сама программа

Новый ролик — кнопка «Проекты» → «Новый проект». Проекты можно копировать
и переносить как обычные папки.


ПРОЕКТ — ЭТО ПАПКА (ОТКРЫТЬ ПАПКУ ИЛИ ZIP)
------------------------------------------
Редактор не привязан к одному ролику: проект — любая папка с project.json.

  моя-папка/
    project.json   порядок сцен, длины, настройки; "editor_min": "2.1" — какая
                   версия программы нужна (старая программа скажет «обновите»)
    scenes/        код сцен
    assets/        картинки, видео, звуки, тексты
    fonts/         шрифты проекта
    lib/           общий код ролика (стиль, компоненты, переходы) — в сцене:
                   from lib.имя_файла import *   (правки в lib/ видны сразу)

«Проекты» → «Открыть проект»:
  • Папка…      — выбрать папку проекта (окно выбора может открыться за браузером);
  • Zip-архив…  — выбрать zip (или перетащить его в окно «Проекты»);
  • путь        — вставить путь к папке или к zip и нажать «Открыть».
Zip распаковывается в папку projects/ рядом с программой и сразу открывается.
Можно и так: положить zip или папку проекта в projects/ — они появятся в списке
«Ваши ролики», щелчок по zip распакует его и откроет.
project.json в архиве может лежать и во вложенной папке — её программа найдёт сама.

Общие файлы для нескольких проектов (например, рилсы большого ролика):
в project.json  "shared": ["../.."]  — программа будет искать assets/, lib/ и
fonts/ ещё и в этой папке (путь относительно проекта).

Новые и открытые проекты — без кинополос, виньетки, зерна и фонового гула,
если их не включили в «Настройках» (у трейлера SHELTER всё как раньше).


БЕЗОПАСНОСТЬ
------------
Редактор работает только на вашем компьютере (адрес 127.0.0.1) — из сети
к нему не подключиться. Изменения принимаются только от открытой страницы
редактора (секретный ключ на каждый запуск), поэтому чужие сайты в браузере
ничего не могут в нём сделать. Код сцены выполняется в отдельных процессах:
зависшая сцена останавливается сама через 40 секунд, редактор продолжает работать.
Код от ИИ перед добавлением проверяется (запрещены файлы, сеть, системные вызовы).

Сцены проекта — это код на Python, он выполняется на вашем компьютере. Поэтому
перед ПЕРВЫМ открытием любого проекта, которого программа ещё не видела (zip,
папка из другого места, новая папка в projects/), она показывает, сколько в нём
файлов с кодом и откуда он, и открывает только после подтверждения. Откажетесь —
только что распакованная из zip папка удаляется. Открывайте только свои проекты
или проекты из надёжных источников.
При распаковке zip программа не пускает файлы за пределы папки проекта (пути
с «..», абсолютные пути, ссылки), пропускает всё, что вне папки с project.json,
и отказывается от подозрительно больших («zip-бомба») архивов.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• Превью долго готовится: рендер идёт на всех ядрах процессора; сложные
  сцены (размытие, много спрайтов, видео 4K) считаются дольше. Экспорт при этом
  точный — он не зависит от превью.
• Видео не загружается: лучше всего MP4 (H.264). MOV/WEBM/MKV тоже подходят.
• Порт занят: программа сама выберет следующий свободный, адрес будет в консоли.
• Сломали сцену и не можете найти ошибку: Ctrl+Z в редакторе кода или «Версии».
  Прошлые версии каждой сцены программа сама складывает в scenes/_history
  (раз в пару минут, последние 20 копий), удалённые сцены — в scenes/_trash.
