SHELTER STUDIO — редактор роликов на Python
===========================================

Внутри трейлер SHELTER, разложенный на 21 сцену. Каждую сцену можно открыть,
поменять код или тексты и сразу увидеть результат, добавить новые сцены
и выгрузить готовое видео в MP4.


ЗАПУСК
------
Нужен Python 3.10 или новее: https://www.python.org/downloads/
(в Windows при установке отметьте галочку «Add python.exe to PATH»).

  Windows:  двойной щелчок по  start_windows.bat
  Mac:      двойной щелчок по  start_mac.command
            (если macOS не даёт открыть: правый щелчок → «Открыть» → «Открыть»)
  Linux:    bash start_linux.sh

Первый запуск 1–3 минуты: программа сама ставит нужные библиотеки
(нужен интернет). Потом открывается браузер с редактором.
Окно с чёрной консолью не закрывайте — это и есть программа.
Закрыли консоль — редактор остановился.

Вручную, если удобнее:
  pip install -r requirements.txt
  python run.py project


КАК ПОЛЬЗОВАТЬСЯ
----------------
Таймлайн внизу
  • каждый блок — сцена; щелчок — открыть её код, двойной щелчок — перейти к ней;
  • перетащите блок, чтобы поменять порядок; тяните правый край — длина;
  • «+ Сцена» — новая сцена из шаблона после выбранной;
  • зелёная полоска над сценами — какие кадры превью уже готовы;
  • оранжевые метки — удары (HITS), нижняя дорожка — звук.

Превью слева
  • Пробел — play/пауза, стрелки — по кадру (Shift+стрелка — на секунду);
  • кадры рендерятся в фоне; если впереди ещё не готово, плеер подождёт.

Вкладки справа
  • Код сцены — Python-код выбранной сцены. Превью обновляется само, пока вы
    печатаете (или по Ctrl+S). Ошибка покажется красным с номером строки.
  • Тексты — все надписи и имена ролика. Меняются без кода.
  • Картинки — свои картинки: кнопка или перетаскивание. «Убрать белый фон»
    вырежет объект со светлого фона. Щелчок по картинке вставит её в код.
  • Настройки — зерно, виньетка, полосы, звук, своя музыка (mp3/wav).
  • Шпаргалка — все команды для сцен с примерами.

Экспорт
  Кнопка «Экспорт MP4» справа вверху. Видео 1920×1080 со звуком
  появится в папке project/exports/.


ГДЕ ЧТО ЛЕЖИТ
-------------
  project/project.json    порядок сцен, длины, тексты, настройки
  project/scenes/*.py     код сцен (можно править и в любом редакторе)
  project/scenes/_trash/  удалённые сцены (их можно вернуть)
  project/scenes/_history/ прошлые версии сцен
  project/assets/         картинки
  project/fonts/          шрифты (Oswald, Cormorant — свободная лицензия OFL)
  project/audio/          загруженная музыка
  project/exports/        готовые видео
  studio/                 сама программа

Чтобы начать новый ролик, скопируйте папку project под другим именем
и запустите:  python run.py путь/к/новой_папке


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• Превью долго готовится: рендер идёт на всех ядрах процессора; сложные
  сцены (размытие, много спрайтов) считаются дольше. Экспорт при этом
  точный — он не зависит от превью.
• Порт занят: программа сама выберет следующий свободный, адрес будет в консоли.
• Сломали сцену и не можете найти ошибку: Ctrl+Z в редакторе кода.
  Прошлые версии каждой сцены программа сама складывает в scenes/_history
  (раз в пару минут, последние 20 копий), удалённые сцены — в scenes/_trash.
